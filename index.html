Кто есть кто

Родственник

  • Один человек = один аккаунт (через Госуслуги)
  • Несколько телефонов; один номер — только у одного аккаунта
  • Мой счёт — единый кошелёк

Близкий

  • Есть в системе один раз
  • Обычно у родственника один близкий, можно несколько
  • У близкого много родственников
  • Перевели — адрес меняется у всех сразу

Карты для звонков

  • Родственник видит и пополняет только те, что купил сам
  • Бумажные карты, купленные самим близким, не видны
  • На карте видно, когда по ней звонили последний раз
